# 企业融资模块 · 方案设计

## 1. 背景

在企业详情页的「企业发展」页签中，新增「企业融资」子模块，展示该企业历次融资记录（轮次、金额、投资方、时间等），数据来源于外部导入的 `投融资.csv`（1299 条记录，覆盖 323 家企业，全部命中当前企业库）。

## 2. 数据源分析

### CSV 表结构

| 字段 | 含义 | 样例 | 说明 |
|---|---|---|---|
| `id` | 融资记录 ID | 20296 | 主键 |
| `entity_id` | 企业 entity_id | 9392078 | **关联企业库** `liqi_enterprise.entity_id`，命中率 100% |
| `entity_name` | 企业名称 | 深圳市某科技有限公司 | 展示用 |
| `rz_time` | 融资时间 | 29/11/2023 00:00:00 | 格式 `dd/MM/yyyy HH:mm:ss` |
| `rz_amt` | 融资金额 | 1000000 / 数千万元 / 未披露 | 混合格式：纯数字(元) / 中文描述 / 未披露 |
| `rz_round` | 融资轮次 | A轮 / 天使轮 / 战略投资 / IPO | 中文轮次，去重约 44 种 |
| `investor_info` | 投资方信息 | JSON `[{name,id}]` | 数组，最多 13 个投资方 |
| `created_time` | 创建时间 | 10/4/2024 18:10:51 | 数据入库时间 |
| `updated_time` | 更新时间 | 24/6/2026 19:01:16 | 数据更新时间 |

### 关键数据特征

- 1299 条记录，覆盖 323 家企业（全部命中企业库 `entity_id`）
- 单企业最多 28 条记录，平均 4 条
- 日期范围：1995 ~ 2026
- 金额字段混合格式（纯数字、中文描述、未披露）
- 投资方为 JSON 数组，需解析展示

## 3. 数据库设计

### 新建表 `liqi_enterprise_financing`

```sql
CREATE TABLE IF NOT EXISTS `liqi_enterprise_financing` (
  `id`            bigint       NOT NULL AUTO_INCREMENT COMMENT '编号',
  `enterprise_id` bigint       NOT NULL COMMENT '企业编号（关联 liqi_enterprise.id）',
  `entity_id`     varchar(64)  NOT NULL COMMENT '外部 entity_id（冗余，用于溯源）',
  `rz_time`       datetime     NULL COMMENT '融资时间',
  `rz_amt`        varchar(128) NULL COMMENT '融资金额（原始文本）',
  `rz_amt_num`    decimal(20,2) NULL COMMENT '融资金额（数值，可解析时填入，用于排序/统计）',
  `rz_round`      varchar(32)  NULL COMMENT '融资轮次',
  `investor_info` text         NULL COMMENT '投资方信息 JSON 数组 [{"name":"...","id":"..."}]',
  `creator`       varchar(64)  DEFAULT '' COMMENT '创建者',
  `create_time`   datetime     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updater`       varchar(64)  DEFAULT '' COMMENT '更新者',
  `update_time`   datetime     DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted`       bit(1)       DEFAULT b'0' COMMENT '是否删除',
  `tenant_id`     bigint       DEFAULT 0 COMMENT '租户编号',
  PRIMARY KEY (`id`),
  KEY `idx_enterprise_id` (`enterprise_id`),
  KEY `idx_entity_id` (`entity_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='力企企业库-融资信息';
```

### 设计说明

- 沿用现有子表模式（与 `liqi_enterprise_shareholder` 等一致）
- `enterprise_id` 关联企业库主键，`entity_id` 冗余用于数据导入
- `rz_amt` 保留原始文本，`rz_amt_num` 尝试解析为数值（用于排序和统计）
- 数据导入脚本：从 CSV 按 `entity_id` 匹配 `liqi_enterprise.id` 后写入

## 5. 前端实现

### 5.1 页面位置

在「企业发展」(`growth`) 页签中，**新增一个融资表格区块**，位于「企业标签」下方、「企业新闻」上方。

### 5.2 展示方案

#### 方案 A：时间线 + 表格（推荐）

```
┌─ 企业发展 ──────────────────────────────────┐
│                                              │
│  企业标签: [存续] [高新技术企业] [专精特新]    │
│                                              │
│  ── 融资概览 ─────────────────────────────    │
│  ┌──────────────────────────────────────┐    │
│  │ 融资轮次  │ 融资时间  │ 金额  │ 投资方  │    │
│  │──────────┼──────────┼──────┼───────── │    │
│  │ A轮      │2023-11   │数千万│ 红杉资本  │    │
│  │ 天使轮   │2021-06   │1000万│ 真格基金  │    │
│  └──────────────────────────────────────┘    │
│                                              │
│  企业新闻: ...                               │
└──────────────────────────────────────────────┘
```

**展示内容：**
- **融资概览统计**（stat 类型）：融资总次数、最新融资轮次、最新融资金额
- **融资记录表格**（table 类型）：轮次 | 时间 | 金额 | 投资方（多投资方用 `、` 拼接展示）

### 5.3 前端数据结构

在 `enterpriseData.ts` 中新增字段：

```typescript
export interface EnterpriseDetail {
  // ... 现有字段
  financing?: FinancingRecord[]
}

export interface FinancingRecord {
  id: number
  rzTime: string
  rzAmt: string
  rzRound: string
  investorInfo: { name: string; id: string }[]
}
```

在 `buildRichTabs()` 函数的 `growth` 页签中，根据 `financing` 数据动态生成两个 section：
1. `stat` 类型：融资总次数、最新融资轮次、最新金额
2. `table` 类型：融资记录列表（时间倒序）

### 5.4 空态处理

- 无融资记录时显示「暂无融资数据」
- 金额为"未披露"时展示为 `—`
- 无投资方时展示为 `—`
